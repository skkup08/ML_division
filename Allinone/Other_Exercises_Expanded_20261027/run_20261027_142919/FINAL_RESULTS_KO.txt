상태: 학습·저장·최종 파일 검증 완료. 기존 모델 및 기존 사용자 원본 보존.
사용 자료: 다각도 운동 영상 829개(26명), Kaggle 운동 인식 영상 440개, 스쿼트 정적 이미지 3,745개.
운동 인식 23종 / GOOD-BAD 7종 / 플랭크·컬의 제한된 오류 분류.
Kaggle 자료에는 GOOD/BAD를 새로 붙이지 않았고, 정적 이미지의 시간 특징은 만들지 않았습니다.

영상 요약 모델의 Mendeley 영상만의 점수와 모든 정밀도·재현율·F1·혼동행렬은 quality_scorecard.csv 및 final_validation.json에 있습니다.

검증: 모델/특징/평가/분할/예측/완료 파일 SHA256 일치. 동일 원본 해시 중복 0개. 동일 source/group의 split 중복 없음.
저장된 14개 GOOD/BAD 모델의 테스트 평가 점수와 원시 연쇄 예측 1,011건을 재현했습니다.
cleanup.json에서 이번 작업의 임시 원본 폴더 삭제와 기존 Drive 원본 보존을 확인했습니다.

한계:
- Mendeley는 피험자 단위 분리지만 이전 실험에도 사용한 자료입니다. 새 외부 검증이 아닙니다.
- 운동별 시간 특징 테스트 영상은 6~25개로 작으며, 실제 서비스 적용에는 성능 개선이 필요합니다.
- Zenodo는 사람/원본 영상 ID가 없어 정적 이미지 참고 점수입니다. 스쿼트 이미지 98%대 점수를 사람 독립 영상 정확도로 해석하면 안 됩니다.
- 플랭크/컬 공개 CSV의 높은 점수도 사람 독립 검증이 아닌 프레임 참고 평가입니다.
- 모델 저장 환경 sklearn 1.9.1 / Python 3.11을 추론 환경에 사용하세요. 로컬 sklearn 1.8.0에서도 저장된 평가·예측이 재현됐지만 환경 일치가 권장됩니다.
- 데드리프트는 보류 상태이며 기존 모델은 삭제하지 않았습니다.

재사용: fitness_expanded_runtime.py는 원본 영상 추론 CLI를 제공합니다. predict_saved_features.py는 저장된 특징 입력용 원시 argmax 참고 예측입니다.
inference_constraints.txt는 호환성 제약이며 완전한 환경 lock은 아닙니다.
