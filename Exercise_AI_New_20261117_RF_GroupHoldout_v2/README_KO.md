# 실험용 운동 자세 분류

Roboflow fitness-training/fitness_merged v4의 제공 Normal/Abnormal 라벨을 사용한 소규모 탐색 실험입니다. 26개 기구 전체 완성 모델이 아닙니다.

- 제공 라이선스: CC BY 4.0. 출처: https://universe.roboflow.com/fitness-training/fitness_merged/dataset/4 . 원 영상 촬영자/권리 및 라벨 근거는 독립 확인하지 못했습니다.
- 원래 8,819 이미지의 증강을 파일명 기준 3,803 프레임으로 줄였습니다. 기존 61개 영상 그룹 모두 원래 split 사이에 누출되어 원래 분리를 폐기했습니다.
- 그룹당 최대 24프레임. 33지점 2D 포즈를 골반 중심·몸통 길이로 정규화한 66차원 특징. 기존 Allinone 데이터 및 모델을 가져오지 않았습니다.
- 기존 49개 출처/manifest 문서에서 해당 출처 및 이름 문자열 일치는 없었습니다. 이름이 변경된 동일 영상까지 배제했다는 뜻은 아닙니다.
- 각 정상·비정상 영상 그룹의 마지막 번호를 시험용으로 지정하고 같은 번호를 두 라벨 모두에서 제외했습니다. 증강 프레임과 동일 영상은 train/test에 공유하지 않습니다.
- 피험자 ID 미제공: 사람 독립 평가가 아닙니다. 두 그룹이 같은 사람·촬영환경일 수 있습니다. 대부분 라벨당 영상 두 개 수준으로 매우 작습니다.
- metrics.json은 작은 영상 홀드아웃의 프레임 단위 점수입니다. 실제 운동 안전성, 전문가 정확도, 다른 사람 일반화, 부상 예방을 입증하지 않습니다.
- 제공 라벨은 영상에서 프레임으로 상속된 약한 라벨입니다. 동작 단계별 오류나 반복 횟수는 학습하지 않았습니다.
- 모델은 연구·점검용이며 실서비스 자세교정 판정에 사용하지 마세요. 학습 실패/부족 운동은 metrics의 상태를 확인하세요.
- 운동명은 데이터셋 표기를 보존합니다. RowingMachineExercise는 시티드 케이블로우 후보이며 조정 에르고미터로 해석하면 안 됩니다. LegPress도 시티드/파워 기종 간 동일성은 검증되지 않았습니다.

## v2 라벨 감사 보정
COCO 라벨과 파일명 운동/품질이 다른 레코드 및 다중라벨 이미지를 제외했습니다. BrenchPress → BenchPress, Abormal → Abnormal, Jumping_Jacks → JumpingJacks는 철자 비교에서만 정규화합니다. 파일명은 정답 검증이 아니므로 일치한 라벨도 여전히 약한 라벨입니다. 이전 v1 결과는 라벨 감사 이전 중간 결과로 폐기합니다.

원본 이미지는 배포자가 640x640으로 늘려 변형했습니다. 체형/각도 특징의 왜곡과 가림 영향이 남습니다. 포즈 특징은 33지점 2D 정규화이며 원본 노트북 구현의 정확한 복원이 아닙니다.
