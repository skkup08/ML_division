# 1398피트니스센터 운동기구 인식 · v2 보강 모델

기존 테스트에서 AP50이 90% 미만이었던 6종에 학습 이미지 516장을 추가해 종별 200장을 확보했습니다. 기존 26종의 ID를 유지한 YOLO11n 탐지기를 미세조정했습니다. 기존 평가를 같은 설정에서 재현한 뒤 새 모델을 평가했습니다.

[모델 파일 크기와 SHA-256](model/checksums.json) · [26종 전체 결과 CSV](metrics/per_class_26.csv)

## 성능

동일한 내부 테스트 205장에 정답 상자 207개가 있습니다. 기구별로는 해당 기구의 AP50, 전체는 26종의 산술 평균인 mAP50을 사용했습니다. AP50은 정답 상자와 예측 상자의 IoU가 0.5 이상일 때 점수 순서에 따른 정밀도·재현율을 요약한 값입니다.

체스트 프레스는 89.34%에서 78.12%로 내려갔고, 보강 대상 밖의 파워 랙도 94.41%에서 85.50%로 내려갔습니다. 전체 mAP50은 소폭 상승했지만 위치 일치 기준을 더 엄격하게 보는 mAP50–95는 하락했습니다. 이번 모델은 현장 비교용 v2 후보입니다.

테스트에 있는 유일한 싯업 벤치 사진을 앱과 같은 정사각 입력으로 별도 추론하면 새 모델의 1위는 하이퍼 익스텐션이었습니다. 점수는 0.809, 이 상자와 정답 위치의 IoU는 0.973이었습니다. 이 한 장에서는 기구 위치를 찾고도 종류를 혼동했습니다. 자세한 상자와 점수는 `metrics/situp_single_image.json`에 포함했습니다.

보강 6종의 평균 AP50은 70.05%에서 73.07%가 됐고 이 중 2종이 90% 이상입니다. 26종 전체에서 AP50 90% 이상인 기구 수는 20종에서 20종이 됐습니다. 싯업 벤치는 테스트가 1장, 케이블 크로스오버는 4장, 메가맥스는 5장입니다. 현장 성능을 판단하려면 별도의 현장 촬영본에 정답 상자를 붙이고 테스트해야 합니다. 모든 점수는 고정된 내부 테스트 세트에서 측정했습니다.

## 구성

- `model/equipment26_anysize.tflite`에는 RGB 입력 전처리와 26종별 후보 추출이 포함됩니다. `model/equipment26_min200.pt`는 여러 기구 인스턴스를 찾을 수 있는 PyTorch 탐지 모델입니다.
- `model/class_mapping.json`에서 모델 출력용 0~25 ID와 센터 기구 번호, 한국어 이름을 확인할 수 있습니다.
- `additions/labels/train`에 보강 이미지 516장의 YOLO 정답 라벨이 있습니다. [이미지 출처](additions/sources.csv)와 [파일별 검수 기록](additions/provenance.json)에서 원본 주소·파일 해시·좌표를 확인할 수 있습니다. `additions/recovered_136.csv`에는 다시 찾은 후보 136장의 원본 주소와 학습 포함 여부가 들어 있습니다.
- `metrics/per_class_26.csv`는 26종 전체의 장수, 정밀도, 재현율, AP50, AP50–95 비교표입니다. JSON의 지표는 0~1, CSV의 `ap50_delta_pp`만 퍼센트포인트 단위입니다. `training_history.csv`에는 에폭별 학습·검증 지표가 있습니다.

## 데이터와 검수

공개 Roboflow 후보 136장의 원본과 주석을 다시 확보했고, 중복 검사·육안 대조를 거쳐 75장을 사용했습니다. 나머지 441장은 공개 기구 제품 페이지에서 선별했습니다. 제품 이미지에는 체육관·중고 장비 사진과 단색 배경 제품 이미지가 섞여 있으며, 판매처별 실사·렌더링 표기는 일정하지 않습니다. 별도로 생성한 이미지나 단순 증강본을 516장에 포함하지 않았습니다. 출처별 원본 링크를 보존했으며 판매처 이미지별 재배포 허가는 확인하지 않았습니다.

기존 세 분할 전체와 후보 간에 지각 해시를 비교했습니다. 기준 사진과 좌우 반전·회전·기구 영역을 대조하고 기존 사진 또는 다른 후보와 가까운 이미지를 제외했습니다. 검증·테스트에 매우 가까운 후보의 제품 그룹도 제외했습니다. 기구 본체와 상자를 육안으로 대조했습니다. 메가맥스는 스미스 가이드 바와 별도 프리웨이트 랙 기능이 함께 있는 장비로 정의했고 온라인 제품 페이지의 랙 사양을 추가 확인했습니다. 제품 그룹·출처는 485개이며 동일 제품의 서로 다른 시점이 일부 포함됩니다.

## 앱 입력과 출력

TFLite 시그니처 이름은 `rank`입니다. 앱이 파일을 RGB 픽셀로 디코딩하고 촬영 방향을 적용한 뒤 `image`에 `uint8 [1, 높이, 너비, 3]`을 전달합니다. 모델이 비율을 유지해 축소·확대하고 여백을 채워 640 × 640으로 맞춘 뒤 정규화합니다. 가로·세로는 양수이며 실제 기기의 메모리 한도가 적용됩니다.

| 반환값 | 형식 | 의미 |
|---|---|---|
| `class_scores` | float32 [26] | 클래스마다 가장 높은 탐지 점수. 여러 기구의 점수 합이 1일 필요는 없습니다. |
| `best_boxes` | float32 [26, 4] | 해당 클래스의 최고점 상자. 원본 사진의 왼쪽·위·오른쪽·아래 좌표를 0~1로 정규화합니다. |

기구마다 최고점 하나를 뽑아 26개 점수를 내림차순으로 정렬합니다. 앱에서 K를 1~26으로 지정하거나 최저 점수를 지정할 수 있습니다. 최저 점수보다 낮은 후보는 생략하므로 결과가 0개일 수도 있습니다. 기본 예제는 상위 3종을 반환합니다.

```bash
python -m pip install ai-edge-litert numpy pillow
python code/predict.py gym.jpg --top-k 3
python code/predict.py gym.jpg --top-k 1 --min-score 0.25
```

학습 사진 `add_21-002.jpg`의 YOLO 정답은 `21 0.4861111 0.4895833 0.9305556 0.9236111`입니다. 첫 값 21은 싯업 벤치이고 다음 네 값은 정규화한 중심 좌표와 너비·높이입니다. [원본 사진과 제품 페이지](additions/sources.csv)

TFLite CPU 변환을 검증 이미지 26장과 가로·세로 크기 변경 입력 2건으로 확인했습니다. PyTorch와 1위 기구가 28/28건 일치했고 모든 클래스 점수의 최대 절대 차이는 0.0000108였습니다. Android·iOS 실기기 속도는 측정하지 않았습니다.

## 학습 재현

원본 ZIP 세 개를 한 폴더에 두고 보강 모델 폴더에서 아래 명령을 실행합니다. 공개 저장소에서는 보강 이미지 516장을 각 출처에서 복원합니다. 원본 페이지가 변경되면 파일명과 해시 오류를 표시합니다. 이미 보강 JPEG 516장을 가지고 있다면 `additions/images/train`에 두면 됩니다. 복원 스크립트는 원본 SHA-256, 최종 이미지·라벨 짝, 클래스별 장수를 검사합니다.

```bash
python -m pip install pyyaml Pillow==13.0.0
python code/fetch_additions.py
python code/restore_dataset.py /path/to/original_zips ./dataset_min200
python -m pip install ultralytics==8.4.194 torch==2.9.1 torchvision==0.24.1
python code/train_min200.py --weights ./baseline_best.pt --data ./dataset_min200/data.yaml --output ./runs --device cpu
```

시작 가중치는 기존 26종 min100 재학습본입니다. SHA-256은 `7af2ceb79edad610f40369bdac110f2aeb80fae40c2921ec95a70eb081bc585b`입니다. [기존 가중치 다운로드](https://raw.githubusercontent.com/skkup08/ML_division/HEAD/SKKU_1398_Fitness_ML/03_training_runs/equipment26_min100_retrain_20261101T020110Z/fit/weights/best.pt)

이번 학습은 전체 3,644장을 사용했습니다. CPU에서 앞의 23개 모듈을 동결하고 탐지 헤드를 미세조정했습니다. 학습 해상도 416, 배치 12, AdamW, 시작 학습률 0.00055, 시드 1398, 최대 8에폭, 조기 종료 대기 4에폭입니다. 총 8에폭을 실행했고 검증 mAP50–95가 가장 높았던 7번째 에폭의 가중치를 배포합니다. 테스트 결과는 가중치 선택에 사용하지 않았습니다.

전후 테스트 설정은 YOLO11n, 해상도 640, 배치 16, 직사각형 배치, 신뢰도 하한 0.001, NMS IoU 0.7, CPU입니다. 원래 학습 당시의 26개 클래스 AP50을 모두 재현했습니다. 원본, 새 모델, 변환 검증의 상세 수치가 `metrics/`에 있습니다.
