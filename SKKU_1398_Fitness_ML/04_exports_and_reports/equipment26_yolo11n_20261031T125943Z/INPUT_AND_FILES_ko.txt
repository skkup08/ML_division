26종 운동기구 모델 — 입력 사진 처리 및 파일 안내

사용 파일: 이 폴더의 best.pt + class_mapping.json + predict_equipment26.py
학습 환경: ultralytics 8.4.194, Pillow. 모델은 26종이며 메가맥스의 독립 테스트 성능은 검증되지 않았습니다.

사진 입력
JPEG, PNG, WebP 등 Pillow가 해독할 수 있는 사진은 가로·세로 해상도와 비율이 달라도 입력할 수 있습니다.
1. EXIF 회전 정보를 반영합니다.
2. 흑백을 RGB로 바꾸고 투명 배경은 흰색으로 합성합니다.
3. Ultralytics가 원본 비율을 유지하여 축소/확대하고 여백을 넣어 640×640 입력을 만듭니다.
4. 정규화와 추론을 수행하고 탐지 상자를 원본 크기의 좌표로 돌려줍니다.

실행 예시 (이 폴더를 다운로드한 뒤 해당 폴더에서 실행)
python predict_equipment26.py photo.jpg --output result.json --annotated result.jpg

앱/서버 코드에서는 EquipmentDetector를 한 번 생성하여 여러 요청에 재사용하세요.
기본 conf=0.25는 임시 기준이며 현장 사진으로 조정해야 합니다.
image_size는 EXIF 회전이 반영된 [너비, 높이]입니다.
bbox_xyxy는 해당 이미지의 좌상단 기준 [x1,y1,x2,y2] 픽셀 좌표입니다.
앱에서도 같은 회전을 반영한 이미지를 표시해야 상자와 사진이 맞습니다.
검출 결과가 없으면 detections=[]입니다. 사진에 항상 26종 중 하나가 있다고 강제하지 않습니다.

주의할 범위
이 전처리는 신경망 가중치 자체가 아니라 Python 추론 코드가 담당합니다.
TFLite/ONNX 모델을 앱에서 직접 실행할 때는 비율 유지 크기 조정, 여백, 정규화, 좌표 복원을 별도로 구현해야 합니다.
HEIC 등 별도 디코더가 필요한 형식과 손상 파일은 JPEG/PNG/WebP로 변환해야 합니다.
초고해상도 파일은 실행 환경의 메모리 제한을 받습니다. 저해상도·극단적인 비율·흐릿한 사진은 인식 성능이 낮아질 수 있습니다.

검증
8가지 사진 입력을 실제 26종 모델에 넣고 640×640 텐서, 원본 크기 복원, 상자 좌표 범위를 확인했습니다.
input_preprocessing_checks.json은 이 입출력 동작 검사이며 새로운 정확도 평가가 아닙니다.
